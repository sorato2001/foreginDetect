🚀 QUICK START FOR WINDOWS USERS:
===========================================

1. Install prerequisites (5 min):
   • Python 3.11+ from https://www.python.org (check "Add to PATH"!)
   • FFmpeg from https://ffmpeg.org or: choco install ffmpeg

2. Run setup wizard (1 min):
   • Double-click: scripts\setup-windows.bat
   • It will create config, directories, and validate installation

3. Configure cameras (5 min):
   • Edit: configs\cameras.yaml
   • Add your camera RTSP URLs and FTP paths

4. Launch (1 click):
   • Option A: Run scripts\create-shortcut.bat, then use desktop shortcut
   • Option B: Double-click scripts\run.bat
   • Option C: Run scripts\run.ps1 from PowerShell
   • Option D: Run from Command Prompt: scripts\run.bat

Total setup time: ~10 minutes

⚠️ IMPORTANT FOR WINDOWS USERS:
===========================================

1. PATH separators in YAML:
   ✅ Use forward slashes:   C:/data/ftp/cam_001
   ✅ Use double backslash:  C:\\data\\ftp\\cam_001
   ❌ NEVER single backslash: C:\data\ftp\cam_001

2. Python installation:
   ✅ Must check "Add Python to PATH"
   ✅ Verify: python --version
   ✅ May need restart after installation

3. FFmpeg installation:
   ✅ Download from ffmpeg.org
   ✅ Add to PATH or specify full path in config
   ✅ Verify: ffmpeg -version

4. FTP directories:
   ✅ Must exist and be writable
   ✅ Create in File Explorer or command line
   ✅ Camera must have permission to write

🔧 QUICK COMMAND REFERENCE:
===========================================

Setup (first time):
  scripts\setup-windows.bat

Run system:
  scripts\run.bat
  .\scripts\run.ps1                    [PowerShell]
  scripts\run.bat configs\cameras.yaml INFO   [Custom config]

Create FTP directories:
  mkdir data\ftp\cam_001
  mkdir data\ftp\cam_002

Check logs:
  type data\logs\event_system.log
  more data\logs\event_system.log
  
View videos:
  start explorer data\video\

Check database:
  sqlite3 data\db\events.db "SELECT * FROM events;"

Stop system:
  Ctrl+C in command window
  OR: taskkill /IM python.exe /F

Check Python:
  python --version

Check FFmpeg:
  ffmpeg -version
